# Perfect Drop

A lightweight one-tap browser game prototype based on the **Perfect Drop** loop.

## Run

Open `index.html` in a browser.

## Controls

- Tap / click anywhere to drop the moving block.
- On game over, tap / click to instantly restart.

## Mechanics included

- Perfect / partial / miss outcomes.
- Near-miss assistance (5% perfect snap).
- Ultra Perfect chance (15%) with bonus score.
- Streak behavior and glow state.
- Progressive speed increase every 5 stacks.
- Best score persistence via `localStorage`.
